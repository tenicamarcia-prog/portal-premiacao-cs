# Portal Ateky Internet - Gestão, Metas & Gamificação (Setor CS)

Plataforma unificada da Ateky Internet para:
- Apuração mensal de métricas com rigor matemático.
- Disputa dos 5 prêmios oficiais do trimestre para N2 e N3.
- Apuração e resgates individuais para N1.
- Visão Geral do Coordenador Fernando compartilhada com os líderes Antônio e Marcos.
- Modo Visualizador somente leitura com senha rotativa mensal pós-apresentação.
- Cerimônia de premiação com vinheta de cinema awards, transição central e dashboard interativo.
